# Release notes

`8.0.1-atm10.5` is a source-first maintenance snapshot for Minecraft 1.21.1
and NeoForge. It is not an official upstream GTCEu release.

The snapshot includes the pinned NeoForge baseline, the manifest-verified
ATM10 recovery layer, recipe-index transaction rollback fixes, and the
compatibility bridges documented in `SOURCE_LINEAGE.csv` and
`docs/RECOVERY_STATUS.md`.

This repository publishes source for review and collaboration. A binary
release remains gated on completing the resource-rights review, corresponding
source checks, and real client/GameTest validation for the exact build.
